# Motion Match

モーションリファレンスの782項目を使う、スマートフォン向けの組み合わせクイズです。3つの動きと名前をタップで対応させます。1・5・10問のセット、カテゴリー指定、苦手復習、途中保存、図鑑、学習記録、オフラインキャッシュを備えています。少数のカテゴリーでは残りの項目数に応じて問題数と組み合わせ数を減らします。

## 起動

```sh
python3 -m http.server 8765 --directory dist --bind 127.0.0.1
```

同じPCで `http://localhost:8765` を開いてください。スマホで通信なしに使うには、HTTPSで配信して初回の「オフライン準備完了」を待ってください。学習記録は端末のlocalStorageに保存します。キャッシュやブラウザの記録が削除されるとオフライン動作や学習記録は失われます。

## 自動チェック

```sh
npm ci
npm test
```

見た目・操作感は人間による確認が必要です。特にスマホでのデモの読みやすさ、名前の選択、拡大表示、機内モードでの再読み込みをご確認ください。

## 出典

デモの描画コード、カテゴリー、項目名、説明文は [TakayuStudio / モーションリファレンス](https://motion-reference.takayustudio.jp/) の2026-10-12時点の公開サイトから取得しました。`reference/`は取得した原本、`dist/vendor/`は実行に必要なデータ・描画コード・CSSです。`dist/renderer.js`は元サイトの描画エンジンをクイズ画面へ接続します。クイズ・学習記録・オフライン処理は新規実装です。

配信用の静的ファイルは `dist/` にあります。CI/CD定義は含めていません。
